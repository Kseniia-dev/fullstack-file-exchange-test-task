# Frontend

Frontend-часть тестового задания описана в корневом [README](../README.md).

Коротко:

- стек: Next.js + React + React-Bootstrap;
- точка входа: `src/app/page.tsx`;
- общие типы, API и форматтеры: `src/shared`;
- UI и экранная логика: `src/features/dashboard`;
- локальные проверки подтверждены: `npm ci`, `npm run typecheck`, `npm run build`.

Основные команды:

```bash
npm ci
npm run typecheck
npm run build
npm run dev
```
